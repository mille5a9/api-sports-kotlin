# Recorded API responses

Unmodified responses from API-NBA v2, recorded in May 2026 and taken from the
MIT-licensed [fabricatorsltd/api-sports](https://github.com/fabricatorsltd/api-sports)
repository (`api-specs/nba`). `RecordedResponsesTest` decodes each one in full so that
fields the real API sends as `null` are caught by the build rather than by users.
